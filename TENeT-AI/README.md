# AI-Powered Telehealth Feasibility & Necessity Tracker

An AI-assisted web application to identify healthcare deserts in Alaska and evaluate the feasibility of telehealth using public healthcare access data and internet connectivity metrics.

---

##  Role of AI in This Project

The AI component acts as a:

- **Telehealth Advisor**  
  Explains whether telehealth is feasible in a selected region.

- **Data Interpreter**  
  Converts complex metrics into simple, human-readable insights.

- **Decision Support Assistant**  
  Recommends:
  - Video consultation
  - Audio-only telehealth
  - Store-and-forward telemedicine
  - Satellite-assisted care (for extreme locations)

The AI **does NOT handle any personal or patient-level medical data**.  
It only uses **aggregated public datasets**.
